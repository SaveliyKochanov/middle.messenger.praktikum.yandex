# Messenger

Веб-мессенджер — учебный проект Яндекс Практикума (Middle Frontend).

- Сайт: https://clever-fudge-648096.netlify.app/

## Стек

- TypeScript (strict)
- Vite
- Handlebars
- SCSS
- ESLint (typescript-eslint), Stylelint (stylelint-config-standard-scss), EditorConfig
- Архитектура — [Feature-Sliced Design](https://feature-sliced.design/) + MVC

Сторонних библиотек для запросов, роутинга и состояния нет — всё реализовано вручную.

## Функциональность

### Авторизация и профиль

- Регистрация, вход и выход через [API Практикума](https://ya-praktikum.tech/api/v2/swagger/#/). После регистрации или входа пользователь попадает в список чатов.
- При старте приложения запрашивается текущий пользователь (`GET /auth/user`), поэтому после перезагрузки сессия сохраняется.
- Изменение данных профиля, пароля и аватара. Аватар загружается через `FormData` и отображается в профиле.

### Чаты

- Загрузка списка чатов пользователя.
- Создание нового чата.
- Добавление и удаление пользователя в выбранном чате по логину.

### Роутинг

- Собственный роутер на History API (`shared/lib/router`): переходы без перезагрузки, работают кнопки «Назад» и «Вперёд», при F5 открывается та же страница.
- В DOM всегда одна страница: при переходе предыдущая размонтируется.
- Проверка доступа на уровне роутера. У каждого маршрута есть уровень доступа:
  - `guest` — только для неавторизованных (вход, регистрация), авторизованного перенаправляет в `/messenger`;
  - `private` — только для авторизованных, остальных перенаправляет на `/`;
  - `public` — доступен всем (`/404`, `/500`).
- Неизвестный адрес ведёт на `/404`.

### Работа с API

- `HTTPTransport` (`shared/api`) на `XMLHttpRequest` и `Promise`: методы `GET`, `POST`, `PUT`, `DELETE`, query string для `GET`, JSON или `FormData` в теле остальных запросов, таймаут, cookie (`withCredentials`).
- `BaseAPI` и API-классы сущностей: `AuthAPI`, `UserAPI`, `ChatsAPI`.
- Типизированные ошибки: `BadRequestError`, `UnauthorizedError`, `ServerError`, `NetworkError`, `TimeoutError`. Ошибки сервера и сети ведут на `/500`, истёкшая сессия — на страницу входа, ошибки запроса показываются в форме.

### Состояние

- Глобальный `store` (`shared/lib/store`) с подпиской на изменения.
- HOC `connect(mapStateToProps)` подключает компонент к store и перерисовывает его только при изменении нужных данных.
- Утилиты `merge`, `set`, `isEqual` (`shared/lib/utils`).

### Компоненты и формы

- Базовый класс `Block` с жизненным циклом (`componentDidMount`, `componentDidUpdate`, `componentWillUnmount`) и перерисовкой при изменении props через `setProps`. Компоненты встраиваются в шаблоны как `{{{Input ...}}}`.
- Переиспользуемые компоненты: `Input`, `Button`, `Form`, `Modal`, `Avatar`, `Message`.
- Валидация форм: единый модуль с правилами на регулярных выражениях (`shared/lib/validation`), проверка по `blur` и при `submit`, ошибки сервера выводятся под формой.
- Пользовательские данные выводятся в шаблонах через `{{ }}` с экранированием — защита от XSS.

### MVC

- **View** — `Block`, страницы и компоненты, разметка на Handlebars;
- **Model** — `store` и API-классы (`entities/*/api`), мапперы ответов сервера (`entities/*/model/mappers.ts`);
- **Controller** — `authController`, `userController`, `chatController` (`entities/*/model`): принимают данные из форм, валидируют, вызывают API, обновляют store и управляют навигацией.

## Страницы

| Путь | Страница | Доступ |
|---|---|---|
| `/` | вход | гость |
| `/sign-up` | регистрация | гость |
| `/messenger` | список чатов и переписка | авторизованный |
| `/settings` | профиль | авторизованный |
| `/settings/edit` | изменение данных профиля | авторизованный |
| `/settings/password` | изменение пароля | авторизованный |
| `/404` | страница не найдена | все |
| `/500` | ошибка сервера | все |

## Установка и запуск

Нужен Node.js 22 (см. `.nvmrc`).

```bash
npm install
```

| Команда | Что делает |
|---|---|
| `npm run dev` | сервер разработки с автообновлением |
| `npm run build` | проверка типов и сборка в `dist` |
| `npm run start` | сборка и запуск собранной версии на порту 3000 |
| `npm run lint` | все проверки: типы (`tsc --noEmit`), ESLint и Stylelint |
| `npm run lint:types` | только проверка типов |
| `npm run lint:scripts` | только ESLint |
| `npm run lint:styles` | только Stylelint |

## Структура

```
src/
  app/       — точка входа, регистрация маршрутов и компонентов, глобальные стили
  pages/     — страницы
  widgets/   — крупные блоки интерфейса (сайдбар, окно чата)
  features/  — действия пользователя (вход, регистрация, профиль, создание чата, добавление и удаление пользователя)
  entities/  — сущности (чат, сообщение, пользователь): ui, API-классы (api), контроллеры и мапперы (model)
  shared/    — HTTPTransport и ошибки API, Block, роутер, store, утилиты, валидация, компоненты, конфиг
```
